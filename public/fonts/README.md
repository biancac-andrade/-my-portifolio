# Fonte Dapper (opcional)

Quando tiver o arquivo licenciado da **Dapper** (ex.: `dapper.woff2`):

1. Coloque o arquivo nesta pasta.
2. Em `src/index.css`, descomente o bloco `@font-face` de Dapper.
3. Troque `--display` para `'Dapper', 'Bodoni Moda', Georgia, serif`.

Enquanto isso, o site usa **Bodoni Moda** (Google Fonts) como título no mesmo espírito editorial.
